Notes:
- Accuracy is correct figures over figures graded; not_in_input and no_answer are left out, as in each run's summary.txt.
- Verdicts 0 in every run in the first table: not_in_input.
- Unit slips: errors matched with a power-of-ten factor (graded.csv's factor column): scale and zeros, and the other errors matched only after multiplying or dividing the prediction by 10 to 1,000,000.
- Format retries: releases whose first reply didn't validate and were asked again; "(n invalid)" were still invalid and graded as missing.
- Format nulls (prompts with units, such as extract_v2): revenue and net income figures still malformed or with an unknown unit on the retry; each made its release an invalid reply (the "(n invalid)" of format retries); – for prompts without units.
- Input tokens / release: run.json's input tokens over its releases, retries included. The same release counts as more or fewer tokens depending on the model's tokenizer; none if a call reported no token counts.
- Cost is run.json's estimate at the run's token prices per million; runs priced by GPU-hour are repriced at $1 per GPU-hour times the run's wall-clock time (--gpu-hourly), so they compare with each other (paid: the price each run recorded). Latency is per call.
